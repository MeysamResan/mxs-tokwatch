# TokWatch v0.1.0 - Windows x64 preview

TokWatch puts your remaining Codex allowance in the Windows system tray. Hover over the percentage gauge to see reset times, available full resets, account plan, and extra credits when Codex reports them.

## Included in this preview

- Native Rust and Win32 application with a circular percentage gauge and compact details panel.
- Automatic Windows light and dark themes, display scaling, and keyboard-accessible controls.
- Manual refresh and automatic refresh every 1, 2, 5, or 10 minutes.
- Automatic selection of the most constrained window in the main Codex pool, with manual window selection available.
- Native Codex executable discovery and reuse of an existing ChatGPT sign-in.
- Cached and unavailable states, optional Start with Windows, and a simulated demo mode.

TokWatch displays allowance percentages, not an exact token balance. Monitoring sends account queries through the official Codex helper without sending model prompts, purchasing credits, or redeeming resets. Authentication stays with Codex.

## Download and run

**Requirements:** Windows 11 x64 and a compatible native Codex installation signed in with a ChatGPT account. Rust is not required to run the executable.

Download **TokWatch-v0.1.0-windows-x64.zip**, extract it into a permanent folder, and run **TokWatch.exe**. The ZIP includes the executable, a quick-start README, and the MIT license. A standalone **TokWatch.exe** is also provided.

Find the icon beside the clock or in the tray overflow. Hover for details, click to keep the panel open, and right-click for settings or Exit. If connection is needed, choose **Connect to Codex**, or sign in through Codex and refresh TokWatch.

**SHA256SUMS.txt** contains SHA-256 checksums for the executable and ZIP. In PowerShell, use `Get-FileHash .\TokWatch.exe -Algorithm SHA256` or `Get-FileHash .\TokWatch-v0.1.0-windows-x64.zip -Algorithm SHA256` and compare the result with the matching entry.

## Validation

- Formatting and strict Clippy checks passed.
- 24 automated tests passed, including protocol and cache behavior, 30 native layout combinations, and 48 tray-icon variants.
- The live-account integration test is opt-in and excluded from the standard test run.
- The executable is a native 64-bit Windows GUI application and imports only Windows system DLLs.

## Known limitations

- This is an unsigned preview build for Windows 11 x64. Windows may display an unknown-publisher warning.
- Fresh browser sign-in has not been validated end to end. If it fails, sign in through Codex and refresh TokWatch.
- Broader interactive tray, display scaling, accessibility, and long-running reliability validation remains outstanding.
- Available fields depend on the Codex version and account. A countdown reaching zero does not confirm that allowance has replenished; the next successful reading determines the balance.
- No installer, automatic updater, usage predictions, or alert notifications are included.
